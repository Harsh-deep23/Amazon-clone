# Amazon Homepage Clone

A static frontend replica of the Amazon e-commerce homepage built entirely with HTML and CSS. This project focuses on modern UI layout techniques, utilizing CSS Flexbox to structure a complex, multi-section web page without the use of external CSS frameworks.

## Technologies Used
* **HTML5:** Semantic page structuring.
* **CSS3:** Custom styling, Flexbox layouts, hover states, and box-model management.
* **FontAwesome:** Integrated via CDN for UI icons (search, location, cart, menu).

## Key Features
* **Global Navigation Bar:** Includes a customized logo, location selector, interactive search bar with category dropdown, and a shopping cart module.
* **Secondary Navigation Panel:** A sub-menu bar featuring quick links and a hamburger menu icon.
* **Hero Section:** Features a background banner image with an overlaid informational message.
* **Product Grid:** A multi-column flexbox layout displaying category cards (Clothes, Electronics, Furniture, etc.).
* **Multi-Tiered Footer:** Includes a "Back to top" action block, categorized informational link columns, and a copyright banner.
